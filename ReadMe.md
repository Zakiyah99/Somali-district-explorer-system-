# SOMALI DISTRICT MANAGEMENT SYSTEM

## Hordhac

Problem-ka aan xalinaayo waa in aysan jirin meel laga heli karo xogaha dagmooyinka iyo gobolada, anigoo ka faaidaysana waxaan hagaajiyay SOMALI DISTRICT MANAGEMENT SYSTEM anigoo isticmaalaya HTML, CSS iyo JAVASCRIPT.
System-ka waxoo ka koobanyhay labo qaybood:

- **Qaybta Dadweynaha**: Halka ay dadku ka raadin karaan xogta degmooyinka
- **Dashboard-ka**: Halka laga soo galinaayo xogaha gobolada, degmooyinka, iyo users-ka


### QAYBTA Dadweynaha
-  Marka hore waxaa dooree Gobolka, then Dagmada.
-  kadib waxaa kuusoo baxaa xogta Dagmada sida Magaca Gudoomiyaha, Dhaqanka ay caanka ku tahay dagmada, Tirada dadka, meesha ay ku taalo.

### Dashboard-ka
- marka hore waxaa waajib ah in login la sameeyo.
- Marka 2aad waxoo User-ka ku daraa Gobolka, kadib Dagmada
- dagmada marka lagu daraayo it must in aad dooratid gobolka then ayaa ku dari kartaa Dagmo.
- kadib Gali Xogta degmada.
- sidoo kale Admin-ka waxoo sameen karaa DELETE, EDIT.

## Qaabka Loo Isticmaalo

### 1. Page-ka Hore
 Halka oo kasoo kacaayo code-ka waa page-kaan `pages/index.html`.

### 2. Dahsboard Login

1. waxaa Click dhahdaa "Admin Login"
2. Gali email iyo password
3. Isticmaal labadaan:
   - Email: `omartood@gmail.com`
   - Password: `omar123`

### 3. Qaybta Gobolada

1. dooro "Regions"
2. Si aad u darto gobol cusub, aad Page-kaan "Add New"
3. Geli magaca gobolka

### 4. Degmooyinka

1. Dooro "Districts"
2. Si aad u darto degmo cusub:
   - Taabo "Add New"
   - Dooro gobolka
   - Gali magaca degmada
3. Si aad u geliso macluumaadka degmada:
   - Taabo "Add Details"
   - Raac tilmaamahaan:
     - **1**: Dooro gobolka iyo degmada
     - **2**: Geli xogta aad rabtid in aad galiso
     - **3**: Geli Map-ka (iframe code)
     - **4**: Geli sawirada
4. Si aad u wax ka beddeshido degmo:
   - Taabo "Edit"

### 5. Users-ka

1. Dooro "Users"
2. Si aad u darto User cusub, Taabo "Add New"
3. Gali magaca, email, iyo password
